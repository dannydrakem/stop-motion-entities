# Stepped Player Animations 0.17.0-beta.1

Первая функционально завершённая бета-версия для Fabric 1.21.1.

## Требования

- Minecraft 1.21.1
- Java 21
- Fabric Loader 0.17.2 или новее
- Fabric API 0.116.5+1.21.1 или новее

Остальные интеграции являются необязательными и активируются автоматически при наличии соответствующих модов.

## Установка

Поместите `stepped-player-animations-0.17.0-beta.1.jar` в папку `mods` клиентской сборки.

## Основные возможности

- Общая частота анимации 8, 12, 24 или 25 FPS.
- Плавное перемещение сущностей при ступенчатой анимации модели.
- Индивидуальное включение эффекта для типов сущностей.
- Настройки через Mod Menu и горячие клавиши.
- Поддержка ванильных моделей, EMF/ETF, Emotecraft, PlayerAnimator, BendyLib, Figura и Flashback.

## Известное ограничение

При одновременном использовании Figura и FA Player Extension предмет в руке может следовать позе FA, а не видимой позе Figura. Каждая система по отдельности работает корректно.
