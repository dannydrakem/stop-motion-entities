# Stop Motion Entities 0.17.0-beta.2

Клиентский мод для Fabric 1.21.1.

## Изменения

- Покадровое вращение и покачивание выброшенных предметов с общей частотой 8, 12, 24 или 25 FPS. Перемещение и падение остаются плавными.
- Отдельная галочка для предметов в списке сущностей, включая поиск и общее включение/отключение.
- Настройки открываются клавишей `;` (`Ж` в русской раскладке). Назначение меняется в управлении Minecraft.
- Включено исправление замирания анимаций при экспорте Flashback и после выхода из повтора.

## Требования и установка

Minecraft 1.21.1, Java 21, Fabric Loader 0.17.2+ и Fabric API 0.116.5+1.21.1 или новее.

Замените предыдущий JAR мода файлом `stop-motion-entities-0.17.0-beta.2.jar` в клиентской папке `mods`.

## Проверка

Сборка проекта и проверка номера версии внутри JAR. Пользователь подтвердил исправление Flashback и анимацию выброшенных предметов в игре.

## Ограничения

- Покадровое колыхание травы и листвы в шейдерах пока не реализовано: для изоляции от воды и других эффектов требуется отдельная поддержка шейдерпаков.
- При одновременном использовании Figura и FA Player Extension предмет в руке может следовать позе FA вместо видимой позы Figura.
