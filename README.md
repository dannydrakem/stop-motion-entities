# Stepped Player Animations

Клиентский Fabric-мод для дискретизации только визуальной позы игрока. Проект развивается небольшими проверяемыми этапами.

## Текущий этап

Этап 12, синхронизация с Flashback: итоговые EMF-позы, ванильные живые модели, вёсла лодок и покачивание вагонеток отображаются в 12 FPS. В обычной игре используется системное монотонное время. При установленном Flashback мод автоматически переходит на его визуальную временную шкалу, включая просмотр, паузу, перемотку и покадровый экспорт.

FA Player Extension, Emotecraft и Just Expressions работают через слой совместимости. Без EMF и ресурспаков ванильные модели обрабатываются отдельным путём.

Зафиксированные версии:

- Minecraft 1.21.1
- Java 21
- Fabric Loader 0.17.2
- Fabric API 0.116.5+1.21.1
- Fabric Loom 1.11.1

Проверенный тестовый набор этапа 3:

- Entity Model Features 3.3.9
- Entity Texture Features 7.2.4
- Emotecraft 2.4.12
- PlayerAnimator 2.0.4+1.21.1
- Fresh Animations 1.10.4
- FA Player Extension 1.1

## Сборка

Требуется JDK 21 (`JAVA_HOME` должен указывать на него).

На Windows:

```text
gradlew.bat build
```

Готовый jar появляется в `build/libs/`.
