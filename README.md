# Stepped Player Animations

Клиентский Fabric-мод для дискретизации только визуальной позы игрока. Проект развивается небольшими проверяемыми этапами.

## Текущий этап

Этап 21: итоговые EMF-позы, ванильные живые модели, вёсла лодок и покачивание вагонеток можно переключать между 8, 12, 24, 25 FPS и режимом без ограничений. Экран Mod Menu содержит подсказки на русском и английском языках, поиск, прокручиваемый список поддерживаемых типов сущностей с индивидуальными галочками и отдельный блок «Включить всех / Отключить всех». Частота остаётся единой глобальной настройкой. Клавиша `'` включает или выключает функцию, `[` выбирает предыдущую частоту, а `]` — следующую. Синхронизация с временной шкалой Flashback сохраняется. Повторные текстурные слои жителей получают ровно ту же удерживаемую позу, броня игрока принимает сгибы конечностей и туловища от PlayerAnimator и сбрасывает их после завершения эмоции.

FA Player Extension, Emotecraft и Just Expressions работают через слой совместимости. Без EMF и ресурспаков ванильные модели обрабатываются отдельным путём.

- Fabric API 0.116.5+1.21.1

## Сборка

Требуется JDK 21 (`JAVA_HOME` должен указывать на него).

На Windows:

```text
gradlew.bat build
```

Готовый jar появляется в `build/libs/`.
