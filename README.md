# Stop Motion Entities

Придайте анимациям Minecraft выразительный покадровый стиль. Настраивайте частоту анимации игроков, мобов и транспорта, сохраняя их перемещение плавным — мод отлично подходит для постановочных роликов, машиним и другого творческого контента.

Текущая версия: `0.17.0-beta.1` для Minecraft 1.21.1.

## Возможности

- Общая частота анимации: 8, 12, 24, 25 FPS или без ограничения.
- Горячие клавиши для включения эффекта и смены частоты.
- Отдельные переключатели для каждого типа сущностей.
- Поддержка ванильных игроков, мобов, лодок и вагонеток.
- Совместимость с EMF/ETF, Emotecraft, PlayerAnimator, BendyLib, Figura и Flashback.
- Настройки через Mod Menu на русском и английском языках.

## Совместимость

Основная проверка выполнена на Minecraft 1.21.1 со следующими версиями:

- Fabric Loader 0.17.2 или новее;
- Fabric API 0.116.5+1.21.1 или новее;
- Entity Model Features 3.3.9;
- Entity Texture Features 7.2.4;
- Emotecraft 2.4.12;
- PlayerAnimator 2.0.4+1.21.1;
- Figura 0.1.6+1.21.1;
- Mod Menu 11.0.5.

Дополнительные моды не обязательны: без них мод обрабатывает ванильные анимации.

### Известные ограничения

При одновременном использовании Figura и FA Player Extension предмет в руке может следовать позе FA, а не видимой позе Figura. Это не влияет на работу каждой из этих систем по отдельности.

## Сборка

Требуется JDK 21.

```text
gradlew.bat build
```

Готовый JAR создаётся в `build/libs/`.
