# Этап 18 — общие переключатели сущностей

Версия: `0.13.0-alpha.2`

## Изменения

- Над прокручиваемым списком добавлен отдельный блок `Все сущности`.
- Галочка `Включить всех` включает обработку для всех строк списка.
- Галочка `Отключить всех` отключает обработку для всех строк списка.
- При смешанных индивидуальных настройках обе общие галочки сняты.
- Общие и индивидуальные галочки синхронизируются сразу, без повторного открытия экрана.
- Массовое переключение сохраняет конфигурацию одной операцией.
- Глобальная частота кадров при массовом или индивидуальном переключении не изменяется.
- На кнопку `Настроить сущности...` добавлена подробная подсказка на русском и английском языках.

## Проверка сборки

Проект успешно собран для Minecraft 1.21.1 на Java 21. Ошибок компиляции и проверки Gradle нет.
