# Этап 17 — индивидуальные переключатели сущностей

Версия: `0.13.0-alpha.1`

## Настройки

- На основном экране Mod Menu появилась кнопка `Настроить сущности...`.
- Она открывает прокручиваемый список поддерживаемых типов сущностей с галочками.
- Галочка включает ступенчатую анимацию для всех экземпляров выбранного типа.
- Снятая галочка оставляет этот тип полностью плавным.
- Настройки сохраняются в `stepped_player_animations.json`.
- В список входят игрок, живые сущности, лодки и все виды вагонеток, для которых мод уже умеет обрабатывать анимацию.

## Глобальная частота

Индивидуальная настройка хранит только состояние `включено/выключено`. Частота кадров не сохраняется отдельно для сущности. Если глобально выбрано `8 FPS`, любая повторно включённая сущность сразу использует те же `8 FPS`.

## Проверка сборки

Проект успешно собран для Minecraft 1.21.1 на Java 21. Ошибок компиляции и проверки Gradle нет.
