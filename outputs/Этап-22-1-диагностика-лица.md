# Этап 22.1 — диагностика лица Just Expressions

Версия: `0.14.0-alpha.1`

## Назначение

Диагностическая версия один раз записывает в журнал фактическую runtime-иерархию частей `head` и `hat` модели игрока при запуске эмоции.

Для каждого элемента выводятся:

- полный путь из ключей дочерних частей;
- фактический Java-класс;
- внутренний ID кастомной EMF-части, если он доступен;
- идентификатор экземпляра для обнаружения общих ссылок между ветками.

Также выводится полный набор ключей ванильных частей, собранных EMF.

## Безопасность

Диагностика выполняется только один раз за запуск клиента и не изменяет дерево модели. Вся функциональность предыдущей версии сохранена.

## Проверка

Нужно запустить любую достаточно долгую эмоцию с включёнными FA Player Extension и Just Expressions, затем передать `latest.log`. Искомый блок начинается строкой:

`Runtime EMF player head hierarchy (diagnostic stage 22.1).`
