# Этап 2 — минимальный Fabric-проект

Дата проверки: 26 сентября 2026 года.

## Результат

Создан минимальный клиентский Fabric-мод для Minecraft 1.21.1. Он успешно собирается и запускается, но намеренно пока не меняет рендер, анимации, физику, камеру, сетевую логику или игровой процесс.

## Зафиксированная платформа

| Компонент | Версия |
|---|---:|
| Minecraft | 1.21.1 |
| Java | 21 |
| Fabric Loader | 0.17.2 |
| Fabric API | 0.116.5+1.21.1 |
| Fabric Loom | 1.11.1 |
| Gradle | 8.14.3 |
| Версия мода | 0.1.0-alpha.1 |

## Что находится в проекте

- отдельная клиентская точка входа;
- `fabric.mod.json` с областью `client`;
- точная зависимость от Minecraft 1.21.1, чтобы пока не заявлять неподтверждённую совместимость;
- официальные Mojang mappings, соответствующие архитектурному исследованию этапа 1;
- Gradle Wrapper для повторяемой сборки;
- один класс инициализации без Mixin и без вмешательства в игру.

EMF, ETF, Emotecraft и PlayerAnimator не добавлены как обязательные зависимости. Их следует подключать на этапе 3 по одной, чтобы причина каждого возможного конфликта оставалась наблюдаемой.

## Выполненные проверки

1. Чистая сборка Gradle завершилась успешно.
2. Повторная офлайн-сборка завершилась успешно: все задачи были актуальны.
3. Итоговый jar содержит `fabric.mod.json` и клиентский класс `SteppedPlayerAnimationsClient`.
4. Версия байткода — 65, то есть Java 21.
5. Выполнен реальный запуск Minecraft 1.21.1 через Fabric Loader 0.17.2.
6. Fabric загрузил `stepped_player_animations 0.1.0-alpha.1` и Fabric API 0.116.5+1.21.1.
7. В render thread получена строка `Stepped Player Animations initialized (stage 2 base build).`.
8. Клиент продолжил загрузку ресурсов без исключения или crash-report; после подтверждения запуск был остановлен вручную.
