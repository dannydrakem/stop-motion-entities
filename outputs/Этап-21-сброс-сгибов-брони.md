# Этап 21 — сброс сгибов брони

Версия: `0.13.0-alpha.5`

## Исправление

Модель брони переиспользуется Minecraft между кадрами, а BendyLib хранит последнее применённое значение сгиба. Поэтому после завершения эмоции броня могла остаться в последней изогнутой позе поверх уже выпрямленной модели игрока.

Теперь при отсутствии активной эмоции мост явно:

- устанавливает нулевой сгиб туловища;
- устанавливает нулевые сгибы обеих рук и обеих ног;
- очищает источник матричного сгиба верхней части тела.

Сброс выполняется в том же проходе, в котором броня копирует обычную позу игрока, поэтому не зависит от следующей эмоции или смены экипировки.

## Проверка сборки

Проект собран для Minecraft 1.21.1 на Java 21 без ошибок.
